# Onboarding page overrides

Overrides `MASTER.md` for setup / checklist screens.

## Layout

- Single column; max content width ~420–480pt mobile, ~520pt desktop.
- Brand "Deskward" top, then one job: role pick OR next checklist item.
- No device list until checklist complete.

## Checklist row

- Icon status (pending / action / done) + title + one-line reason.
- Primary CTA full-width min height 52pt.
- Secondary text button: "Neden gerekli?"

## Role picker

- Three options as large tappable rows (not tiny chips).
- iOS: hide or disable "Uzaktan erişilecek" with helper text.

## Security copy

- Never say "güvenli" alone — say what is required (permission, password, Tailscale).
- Errors: actionable, no blame.

## Color

- Use accent `#059669` only for complete / primary CTA.
- Destructive only for blocked host / auth lockout.
